## 📌 About the Project

**AgeMate** is a web-based age calculator designed to calculate age using a date of birth. It provides a simple interface for entering a birth date and viewing the calculated result.

This project was created to practice frontend development and JavaScript date handling while building a useful everyday web utility.

## ✨ Features

- 🎂 Calculate age from a date of birth.
- 📅 Select a birth date using the date input.
- ⚡ Calculate results directly in the browser.
- 🎨 Simple and user-friendly interface.
- 📱 Use the website from a modern web browser.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 How to Use

1. Open the [AgeMate website](https://bishaleyyy.github.io/AgeMate/).
2. Enter or select your date of birth.
3. Click the calculation button.
4. View the age result displayed by the application.

*The available controls and displayed results depend on the current implementation.*

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Bishaleyyy/AgeMate.git
   ```

2. Open the project folder:

   ```bash
   cd AgeMate
   ```

3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No package installation or build process is required for a basic HTML, CSS, and JavaScript project.
